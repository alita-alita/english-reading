# 原型验收

## 视觉参考与实现

使用内置 Image Gen 生成阅读界面概念，保存为 reading-concept.png。提示要求：中文三至六年级家庭阅读产品，白底森林绿，左侧英文故事、右侧原因题，原文依据高亮、检查答案与三级提示；所有交互文字用代码实现。

在 Codex 内置浏览器操作和截图。使用 view_image 查看概念与最终桌面截图，对照检查：

1. 页面结构：保留顶栏、居中标题、三步流程及桌面双栏，手机改为单栏。
2. 配色：白背景、#225d4c主色、浅绿色依据高亮及桃色提示图标。
3. 排版：英文衬线正文，中文系统字体；修正按钮导致整句独占一行的问题，使句子连续换行。
4. 组件：圆角描边面板、圆形段落编号、单选框、实心主按钮及描边提示按钮。
5. 文案：原文、题目、四个选项、导航及两个核心按钮一致。
6. 响应式：1505×1045桌面视口及390×844手机视口；手机document宽度与视口均为390，无横向溢出。

有意调整：头像名从Lily改为小读者；增加题目进度、依据操作提醒和页尾原型说明；初始未选择依据时无高亮；提示区初始文案为操作引导。字体形态与概念图有系统字体差异，未宣称像素级复刻。实际采用统一组件和样式实现参考的视觉结构。

## 功能验证

- 正确答案但错误依据 → 提示重新找依据。
- 使用提示、选中正确原文 → 给出原文支持的讲解。
- 完成两道题 → 家长端准确显示1篇、2题、1次提示。
- 选择真实本地测试图片 → 图片预览 → 校对表单 → 保存 → 转换为阅读页面。
- 原型不把图片预览伪装成OCR识别结果。
- 验证数据经界面移除，交付时无测试作业及成绩。
- npm run build通过。
