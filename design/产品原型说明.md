# 小小阅读家 · 第一版交互原型

面向三至六年级家庭，以原创短故事和家庭上传的阅读作业为入口，训练理解原因与回文找依据。无付费。

## 原型边界
真实实现：页面切换、年级筛选、图片选择与预览、多图排序删除、文本校对、手动录入原题、故事练习、分层提示、证据选择、学习记录、本地保存、家长端。
未接入：OCR、AI生成解析、云端账号、跨设备同步。上传图片不发送到服务器。自定义作业可作答和标记依据，但没有答案标注时不自动判断。

## 核心流程
故事 → 阅读与选择 → 点击原文句子作为依据 → 检查 → 分层提示或完成 → 本地学习记录。
作业 → 多图上传 → 原图预览与排序 → 人工校对/录入文章和题目 → 保存 → 练习。

## 验证目标
区分答案正确与证据充分；记录提示次数。家长看到实际完成记录，无演示成绩混入。

## 视觉方向
白底、深森林绿 #225d4c、浅鼠尾草选中态、桃色局部强调。阅读正文用 Georgia 衬线，中文用系统字体；桌面双栏阅读与问答，手机单栏。圆角20px，轻描边，避免游戏化噪声。
