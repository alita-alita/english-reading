# 小小阅读家

三至六年级家庭英语阅读交互原型。React + Vite，本地运行，无付费。

## 启动

```sh
npm install
npm run dev -- --port 5178
```

打开 http://127.0.0.1:5178 。生产构建：`npm run build`。

## 可体验功能

- 年级筛选、四篇原创示例故事。
- 选答案、点选原文依据、三级提示、多题完成反馈。
- 多图选择、预览、排序与移除；人工校对/粘贴文章和原题。
- 自定义作业保存后转为互动阅读；未标注答案的作业不自动判分。
- 家长端：实际阅读记录、题目数和提示次数。
- 浏览器本地保存作业文字和完成记录，桌面与手机响应式布局。

## 当前边界

已开发通义千问 AI 服务端接口，配置密钥后可使用；保留 macOS Vision 本地文字识别与本地规则出题。尚未接入登录、云端存储、跨设备同步或真实家长权限隔离。家长端是原型中的身份切换。本地模式的图片仅发送到本机；AI 模式会将图片和正文发送至配置的通义千问服务。原图不落盘，不保存到作业。所有记录仅在本机浏览器中可用。清理浏览器数据会清除记录。

下一阶段：真实模型质量评测、家庭账号、权限及云端保存。

## 翻译对照与单词库

完成所有题目的答案与依据后，第四步逐句显示中英对照。四篇示例提供人工编写译文；上传作业支持选填中文译文，按段落和句子顺序对应，未提供时明确显示缺少译文。

在第1至第4步点击原文中的英文单词，可编辑中文释义并收藏；同时保存英文原句、句子译文与故事来源。同一单词合并，不同原句累积。我的单词库支持搜索、释义编辑、待复习筛选和翻卡复习。所有数据沿用本地保存；内置小型示例词表，尚未接入在线词典或自动翻译。

阅读区通过“查词收藏 / 标记依据”模式切换，分开处理点词和点句操作。


## 图片识别与自动出题

`npm run dev -- --port 5178` 在 Mac 上启动时自动编译 Vision 识别程序（需要系统 Swift 工具链）。通过本机 `/api/recognize` 识别英文印刷文字，显示低置信度文字提醒；不发送到外部平台。图片只在内存中处理，不保存原图。非 Mac 环境可粘贴英文使用出题流程，但图片识别不可用。生产静态构建不包含此本机服务，正式部署需要独立OCR后端。

流程：上传图片 → 识别英文 → 人工校对 → 选择3/4/5题 → 生成草稿 → 修改题目、正确答案、原文依据和解析 → 检查预览 → 确认后保存到我的作业。之后开始练习，完成时保存学习记录。

本地出题仅使用可核对的规则：because/so 明确因果、原文句子顺序、词句细节。它不是AI推理出题；没有明确因果的文章不强行生成推断原因题。原文太短或细节不足时提示补充，不复制凑数。修改原文后必须重新生成，以免依据错位。

## 单词发音

收藏窗口、单词库、复习卡提供“听发音”。使用浏览器的 SpeechSynthesis，优先设备英语语音，美式优先，略慢语速；支持停止、切词取消、关闭窗口停止。设备不支持或10秒未启动时提供提示。音质及可用性取决于设备英语语音与浏览器；并非预录真人音频。

## 文章朗读

阅读区“听全文”按原文顺序逐句朗读，提供暂停、继续、停止及慢速/稍慢/正常语速；播放中高亮当前句。播放时锁定语速，停止后可调整。使用设备英语语音，语音合成的可用性取决于浏览器和设备。点词播放单词时停止文章；离开文章或进入翻译对照时停止。已在内置浏览器验证播放启动、句子推进、暂停继续、停止和390宽布局；真机声音质量需试听。

## 通义千问 AI 接入

真实导入入口已替代固定演示页。AI 模式：上传图片 → 识别正文与原有四选一题 → 家长校对 → 保留原题 / 补充新题 / 只生成新题 → 检查答案、依据与逐句译文 → 确认保存。

1. 在阿里云百炼开通模型服务，创建与所用地域一致的 API Key。不要在聊天、前端代码或 Git 中填写密钥。
2. 将 `.env.example` 复制为 `.env.local`，在本机文件中填写 `DASHSCOPE_API_KEY`。默认使用北京地域兼容接口与 `qwen3-vl-flash`，可通过 `QWEN_BASE_URL` / `QWEN_MODEL` 修改；所选模型需支持图片输入和 JSON 输出。
3. 重启开发服务：`npm run dev -- --port 5178`。前端只读取服务是否配置，不会获得密钥。
4. 正式部署在 Vercel 中配置同名环境变量，并设置 `AI_ACCESS_CODE`（家庭使用码），随后重新部署。Vite 构建目录为 `dist`，`api/*.mjs` 为服务端函数，仅上传 `dist` 的静态托管不能调用 AI。

AI 接口：`GET /api/ai-status`、`POST /api/ai-recognize`、`POST /api/ai-generate`。图片识别前缩放到最长边1600像素；逐张上传，最大6张。模型返回结果检查题数、四个不同选项、答案范围、有效句子编号、译文对齐及原题未被修改。校验只确保结构和引用位置，不能证明答案正确，仍须家长核对。

生产环境缺少家庭使用码时拒绝 AI 调用。使用码仅保留在当前页面内存；这是家庭试用门槛，不替代账号系统。每个进程内对每个来源每小时限制30次调用，Serverless 多实例下不构成全局额度；公开运营前需账号认证、共享限流和云端额度控制。请在阿里云后台设置预算/用量提醒。AI 请求超时后不自动重试，以免重复计费。

多页原题跨页、非四选一题和模糊文字可能识别不完整，应对照原图核对或分开导入。默认不把手写答案作为标准答案。

验证：`npm test` 检查原题保留、非法依据、译文错位、答案范围、服务未配置、上游错误及生产使用码保护。测试使用模拟模型响应，不代表真实 AI 识别或出题质量已通过评测。

官方接口说明：[通义千问视觉理解](https://www.alibabacloud.com/help/en/model-studio/vision)。
