# 小小阅读家

三至六年级家庭英语阅读交互原型。React + Vite，本地运行，无付费。

## 启动

```sh
npm install
npm run dev -- --port 5178
```

打开 http://127.0.0.1:5178 。生产构建：`npm run build`。

## 可体验功能

- 年级筛选、四篇原创示例故事。
- 选答案、点选原文依据、三级提示、多题完成反馈。
- 多图选择、预览、排序与移除；人工校对/粘贴文章和原题。
- 自定义作业保存后转为互动阅读；未标注答案的作业不自动判分。
- 家长端：实际阅读记录、题目数和提示次数。
- 浏览器本地保存作业文字和完成记录，桌面与手机响应式布局。

## 当前边界

已接入 macOS Vision 本地文字识别与本地规则出题。尚未接入AI、登录、云端存储、跨设备同步或真实家长权限隔离。家长端是原型中的身份切换。图片仅发送到本机识别服务，不传外部平台；识别后不落盘，不保存到作业。所有记录仅在本机浏览器中可用。清理浏览器数据会清除记录。

下一阶段：接入AI生成更丰富的推断题；实现家庭账号、权限及云端保存。

## 翻译对照与单词库

完成所有题目的答案与依据后，第四步逐句显示中英对照。四篇示例提供人工编写译文；上传作业支持选填中文译文，按段落和句子顺序对应，未提供时明确显示缺少译文。

在第1至第4步点击原文中的英文单词，可编辑中文释义并收藏；同时保存英文原句、句子译文与故事来源。同一单词合并，不同原句累积。我的单词库支持搜索、释义编辑、待复习筛选和翻卡复习。所有数据沿用本地保存；内置小型示例词表，尚未接入在线词典或自动翻译。

第1至第3步的句末提供独立“标记依据”按钮，与点词收藏分开操作。


## 图片识别与自动出题

`npm run dev -- --port 5178` 在 Mac 上启动时自动编译 Vision 识别程序（需要系统 Swift 工具链）。通过本机 `/api/recognize` 识别英文印刷文字，显示低置信度文字提醒；不发送到外部平台。图片只在内存中处理，不保存原图。非 Mac 环境可粘贴英文使用出题流程，但图片识别不可用。生产静态构建不包含此本机服务，正式部署需要独立OCR后端。

流程：上传图片 → 识别英文 → 人工校对 → 选择3/4/5题 → 生成草稿 → 修改题目、正确答案、原文依据和解析 → 检查预览 → 确认后保存到我的作业。之后开始练习，完成时保存学习记录。

本地出题仅使用可核对的规则：because/so 明确因果、原文句子顺序、词句细节。它不是AI推理出题；没有明确因果的文章不强行生成推断原因题。原文太短或细节不足时提示补充，不复制凑数。修改原文后必须重新生成，以免依据错位。

## 单词发音

收藏窗口、单词库、复习卡提供“听发音”。使用浏览器的 SpeechSynthesis，优先设备英语语音，美式优先，略慢语速；支持停止、切词取消、关闭窗口停止。设备不支持或10秒未启动时提供提示。音质及可用性取决于设备英语语音与浏览器；并非预录真人音频。

## 文章朗读

阅读区“听全文”按原文顺序逐句朗读，提供暂停、继续、停止及慢速/稍慢/正常语速；播放中高亮当前句。播放时锁定语速，停止后可调整。使用设备英语语音，语音合成的可用性取决于浏览器和设备。点词播放单词时停止文章；离开文章或进入翻译对照时停止。已在内置浏览器验证播放启动、句子推进、暂停继续、停止和390宽布局；真机声音质量需试听。
